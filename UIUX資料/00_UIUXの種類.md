# UI/UX の種類 一覧(2026-11-13)

「UI/UX」と言ったときに出てくるものを、種類ごとに分けた地図。細かい決まりと数値は `../UIUXスキル表.md` にある。
**店舗サイト**の欄は、ノレンの店舗サイトでどれくらい使うか: ◎ 毎回使う / ○ ときどき / △ ほぼ使わない。

## 1. UI と UX の違い
| 言葉 | 中身 | 例 |
|---|---|---|
| UI(ユーザーインターフェース) | 人とサービスの**接点**。目で見て、触るもの | ボタン、文字、色、メニュー、フォーム |
| UX(ユーザー体験) | 知ってから使い終わるまでの**体験全体**。使いやすさ・分かりやすさ・気持ち | Instagram で見つける → サイトで値段を確かめる → 迷わず電話できる → 来店して満足する |
| CX(顧客体験) | UX より広い。店との**すべての接点**(接客・電話・会計・口コミ) | 電話の応対、店内の居心地、再来店の案内 |
| ユーザビリティ | UX の一部。**使いやすさ**(迷わない・間違えない・早い) | 予約ボタンがすぐ見つかる |
| アクセシビリティ | **誰でも**使えるか(高齢者・色覚・視覚・片手) | 文字が大きい、色の差が十分 |

## 2. UI の種類(インターフェースの形)
| 種類 | 中身 | 例 | 店舗サイト |
|---|---|---|---|
| GUI(グラフィカル) | 画面の絵・ボタンを押して使う | Web サイト、アプリ | ◎ |
| タッチ UI | 指で押す・スワイプする | スマホのサイト | ◎ |
| CUI / CLI(文字入力) | 文字でコマンドを打つ | ターミナル | △ |
| 会話型 UI(チャット) | 会話で用事を済ませる | LINE の自動応答、チャットボット | ○ |
| 音声 UI(VUI) | 声で操作する | Siri、スマートスピーカー | △ |
| ジェスチャー UI | 体の動きで操作する | 手を振る、カメラ認識 | △ |
| AR/VR・空間 UI | 現実に重ねる・仮想空間 | 家具の試し置き、Vision Pro | △ |
| ノーUI / 自動化 | 画面を使わず勝手に済む | 自動の予約リマインド通知 | ○ |
| 物理 UI | 実物のボタン・紙 | 券売機、店頭の QR コード、メニュー表 | ○ |

## 3. UX の領域(仕事・分野の種類)
| 領域 | 何をするか | 成果物 | 店舗サイト |
|---|---|---|---|
| UX リサーチ | 使う人を調べる(話を聞く・観察する・数字を見る) | ペルソナ、課題の一覧 | ◎(店主の壁打ち・よくある質問) |
| 情報設計(IA) | 情報を分けて並べ、名前を付ける | サイトマップ、ページの構成 | ◎ |
| インタラクションデザイン | 押したら・動かしたら・どうなるか | 画面遷移、状態の設計 | ○ |
| ビジュアルデザイン / UI デザイン | 見た目(文字・色・余白・写真) | デザインカンプ、スタイル | ◎ |
| UX ライティング | ボタン・見出し・説明の言葉 | 文言の一覧、マイクロコピー | ◎ |
| コンテンツデザイン | 何をどの順で載せるか | 原稿、FAQ | ◎ |
| アクセシビリティ | 誰でも使えるようにする | チェックリスト(WCAG) | ◎ |
| モーションデザイン | 動きで分かりやすくする | アニメーションの決まり | ○(控えめ) |
| サービスデザイン | 店の体験全体を設計する(Web 以外も) | カスタマージャーニーマップ | ○ |
| デザインシステム | 部品と決まりをまとめて使い回す | 色・文字・部品の一覧 | ○(ノレンの型) |
| グロース / CRO | 数字を見て成約を増やす | 計測、改善の仮説 | ○ |
| ユーザビリティ評価 | 使いにくい所を見つける | テスト結果、改善の一覧 | ◎(公開前の 5 人テスト) |

## 5. レイアウトの種類
| 種類 | 中身 | 向く場面 | 店舗サイト |
|---|---|---|---|
| 1 カラム | 縦に 1 列 | スマホ、読み物 | ◎(スマホはこれ) |
| 2 カラム | 本文+横の欄 | ブログ、PC | ○ |
| グリッド | 同じ大きさの箱を並べる | メニュー、写真 | ◎ |
| カード型 | カードを並べる | 特徴、スタッフ | ◎ |
| ジグザグ(交互) | 写真と文を左右交互に | 特徴の説明 | ○ |
| スプリット | 画面を左右に分ける | PC のヒーロー | ○ |
| フルスクリーン | 画面いっぱいの写真 | ブランドの印象 | △(次の内容が見えなくなる) |
| ブロークングリッド / 非対称 | わざと崩す | おしゃれな印象 | △(第一印象で損しやすい) |
| ランディングページ(LP) | 1 ページで行動まで導く | 広告・キャンペーン | ◎ |
| 視線の型: F 型・Z 型 | 目の動きに沿って置く | 配置の説明 | ○ |

| スタイル | 特徴 | 印象 | 店舗サイト |
|---|---|---|---|

| フラット | 影なし・平面 | すっきり(押せそうに見えにくい) | ○ |
| マテリアル | 紙の重なり、少しの影(Google) | 分かりやすい | ○ |
| スキューモーフィズム | 本物の質感を再現 | 懐かしい、重い | △ |
| ニューモーフィズム | 背景と同色の浮き出し | 柔らかい(コントラスト不足) | △ |
| グラスモーフィズム | すりガラスの半透明 | 今っぽい(文字が読みにくい) | △ |

## 7. UX の調べ方・確かめ方の種類
| 方法 | 何が分かるか | 人数・手間 | 店舗サイト |
|---|---|---|---|
| インタビュー | なぜそうするか、困りごと | 5〜8 人 | ◎(店主・常連) |
| ペルソナ | 誰に向けるか | 1〜3 人分 | ○ |
| カスタマージャーニーマップ | 知る → 来店までの流れと不安 | 1 枚 | ○ |
| ユーザビリティテスト | 使えるか、どこで迷うか | 5 人 | ◎ |
| ヒューリスティック評価 | 原則(ニールセンの 10 原則)に照らして点検 | 1〜3 人の専門家 | ◎ |
| カードソーティング | 情報の分け方・名前 | 15 人前後 | △ |
| アンケート | 多くの人の傾向 | 数十〜数百人 | ○ |
| アクセス解析(GA4) | どこから来て何を押したか | 自動 | ○ |
| ヒートマップ・録画(Clarity) | どこまで見て、どこを押したか | 自動 | ○ |
| A/B テスト | 2 案のどちらが良いか | 月に数千人以上 | △ |
| 競合調査 | 同じ業種のサイトの定番 | 5〜10 サイト | ◎ |

## 8. 心理・法則の種類(サイトで使うもの)
| 分類 | 代表 | 一言で |
|---|---|---|
| 使いやすさの原則 | ニールセンの 10 原則 | 状態を見せる・客の言葉・一貫性・エラー防止 など |
| 操作の法則 | フィッツ、ヒック、ドハティ | 大きく近いボタンは押しやすい / 選択肢は少なく / 0.4 秒以内に反応 |
| 記憶の法則 | ミラー(チャンキング)、系列位置、ツァイガルニク | まとめると覚えやすい / 最初と最後が残る / 途中は気になる |
| 見え方の法則 | ゲシュタルト(近接・類同・共通領域・閉合) | 近い・似ている・囲まれているものは仲間に見える |
| 印象の法則 | 美的ユーザビリティ、ピーク・エンド、第一印象 50ms | 見た目が良いと使いやすく感じる / 一番良い時と最後が残る |
| 期待の法則 | ヤコブ、メンタルモデル | よそと同じ形が一番分かりやすい |
| 注意の法則 | フォン・レストルフ、バナー無視、F 型 | 1 つだけ違うと目立つ / 広告っぽい物は見られない / 行の頭しか読まれない |
| 行動の法則 | デフォルト効果、目標勾配、選択肢の過多 | 初期値が選ばれやすい / ゴールが近いと進む |
| 避けるもの | ダークパターン | 偽の期限・隠れた費用・最初からチェック済み |

詳しい中身は `01_原則と法則.md`。
