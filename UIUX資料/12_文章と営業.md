# 日本語の文章の基準と、UI/UX を伝える営業

調べた日: 2026-11-13。根拠の強さ: A = 法令・公的資料(公式の一次資料を含む)/ B = 業界・民間の調査 / C = ブログ・慣習。
`UIUXスキル表.md` の #101〜120 と `05_中身と成約.md` の #1〜14・#23〜24(拾い読み、結論を先に、1 文 50〜60 字、算用数字、外来語、ボタンの文言、総額表示)と重なるものは「→05-◯」と書いて、ここには新しく分かったことだけを書く。

## 3 行の要点
1. **表記は「公用文作成の考え方」(2022)を土台に、店のサイト用に 1 つにそろえる**。半角の算用数字と 3 桁のコンマ(5,500円)、「1か月」、「ください・こと・とき・など」はひらがなで書く。「ございます」は使わず、「させていただきます」は相手に許可をもらうときだけ使う(敬語の指針の例は、まさに「本日、休業させていただきます」)。
2. **営業で言うべきなのは公的資料の数字**。①「Instagram があれば十分」には、Google のガイドラインで **ビジネスプロフィールのウェブサイト欄に SNS のページは入れられない** と返せる。②「ポータルで足りる」には、公取委の調査(2020)で **加盟店の約 11% が契約を一方的に変えられ、高いプランの店ほど上に表示されていた** と返せる。③「高い・効果が分からない」は中小企業がデジタル化で困っていることの 1 位と 2 位(56.2%・50.0%)なので、正面から答える。
3. **「無料」と書くなら、無料の範囲と後からかかる費用を「無料」のすぐそばに書く**(消費者庁のフリーミアムの留意事項と打消し表示の留意点。スマホでは 1 スクロール以上離すと問題になりうる)。制作者側は、申込書に「何を作るか・いくらか・いつ払うか」を書面で残す(フリーランス法 3 条)。GitHub Pages の規約にも気をつける。

## 未確認・意見が割れていること
- **「〜」を使うか**: 公用文は「10時～12時」を例に挙げているが、やさしい日本語のガイドラインは「誤解を生むため使用しない」としている。ノレンでは、ふつうの店は「〜」、外国人のお客さんが多い店は「から・まで」にする、と使い分ける案を出しておく。スクリーンリーダーが「〜」をどう読むか、波ダッシュ(〜 U+301C)と全角チルダ(～ U+FF5E)のどちらがよいかは確かめていない。
- **記者ハンドブック(共同通信社)**: 本で売られていて、ネットでは本文を確かめられなかった。この表の表記は公用文にそろえた。
- **時刻のコロン(11:00)**: 公用文の例は「午後2時 37分」で、コロンの書き方は決めていない。日付と時刻の決まり(JIS X 0301)は今回は見ていない。店のサイトで「11:00」と書くのは慣習(C)。
- **デジタル庁デザインシステムの文言ガイド**: 入力欄(インプットテキスト)の決まりは確かめた。サイト全体の「ウェブコンテンツガイドライン」(DS-680.2)は作っている途中と読める資料があるだけで、本文は確かめられなかった。
- **小規模事業者のホームページ保有率**: 中小企業庁の白書(2018 年版の IT の章)と 2017 年の研究会資料は、サーバーが取得を断ったため、本文の数字を確かめられなかった。85.9%(ラクスル)は従業員 2〜100 人が対象で、従業員 1 人の個人店の数字ではない。「中小企業の 56.7% が保有」という数字はコラムにあったが、出典が分からないので使わない。総務省の通信利用動向調査(企業編)は、常用雇用者 100 人以上の企業が対象なので、個人店には当てはめない。
- **価格**: STUDIO 以外(ペライチ・Wix・Jimdo)は、公式ページの金額を取得できなかった。営業資料に載せる前に、ブラウザで公式ページを開いて確認日を書き直す。
- **特商法の「営業のため」**: 名前は事業者でも中身が個人用なら特商法が当てはまる、という消費者庁の通達の考え方は、今回は本文を確かめられなかった。ホームページの契約で「本当に営業のためか」が争いになった判例があるかも確かめていない。
- **店主向けの広告と景表法**: 景表法は「一般消費者」を守る法律なので、事業者だけに向けた広告は対象から外れる、という解釈が一般的とされる。ただし、消費者庁がそう書いた一次資料は確かめていない。個人店の店主は消費者に近い、と見られる可能性もある。
- **「させていただく」の受け止め方**: 敬語の指針は「適切か」の線引きを示しただけで、「使うな」とは言っていない。指針も、条件を満たしていなくても、満たしているように見立てて使う言い方が広がっていると書いている。年配のお客さんが多い店では、丁寧すぎるくらいが好まれることもある(調査はない)。
- **やさしい日本語のガイドライン**: 今回中身を読めたのは「案」と書かれた PDF だった(出入国在留管理庁のサイトのもの)。確定版と細かいところが違う可能性がある。
