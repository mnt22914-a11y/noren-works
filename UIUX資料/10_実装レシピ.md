# 作り方のレシピ集(2026-11-13)

`06_やりたいこと逆引き.md` の判定 ◎・○ の項目を、ノレンの決まり(1 サイト = 1 つの `index.html`、CSS/JS はインライン、外部読み込みは Google Fonts まで、GSAP・Lenis なし、JS が止まっても全部見える、`prefers-reduced-motion` と `?static=1` で動きを止める、GitHub Pages で公開)の中で作るためのコード集。
ブラウザ対応は MDN の互換データ(@mdn/browser-compat-data 8.1.9、2026-11-12 更新版)を 2026-11-13 に読んで書いた。

## 3 行の要点
1. **隠すのは「JS が動いていて、動きが許されているとき」だけ。** 全部のレシピは `.js:not(.static)` か `@media (prefers-reduced-motion: no-preference)` の中で隠したり動かしたりする。JS がこけたら `static` を付けて全部見せる。
2. **新しい CSS(`animation-timeline`・`::details-content`+`interpolate-size`・`@view-transition`)は `@supports` で囲って「動かないだけ」にする。** `interpolate-size` は 2026-11 時点で Chrome 系だけ、ページをまたぐビュー遷移は Firefox がまだ(preview)。
3. **店主の更新は「Google スプレッドシートを CSV で公開 → 読むだけ」が一番手間が少ない。フォームは Google フォームの埋め込みか、Formspree / Web3Forms などの受け口に `fetch` で送る。** reCAPTCHA・hCaptcha・Turnstile は外部スクリプトなのでノレンの決まりとぶつかる → まずは「見えない罠の欄(ハニーポット)」+サービス側の迷惑判定で受ける。

## 共通の土台(js/static クラスの切り替え、reduced-motion の一括停止)

### `<head>` のいちばん上に置く
```html
<html lang="ja">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
<script>
(function () {
  var d = document.documentElement;
  var q = new URLSearchParams(location.search);
  d.classList.add('js');
  if (q.get('static') === '1' || matchMedia('(prefers-reduced-motion: reduce)').matches) {
    d.classList.add('static');
  }
  // 本体の JS がエラーで止まったら、隠したものを全部見せる
  addEventListener('error', function () { d.classList.add('static'); });
})();
</script>
```

### CSS の一括停止
```css
/* OS の「視差効果を減らす」/ ?static=1 のときは動きを全部止める */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;
    transition: none !important;
    scroll-behavior: auto !important;
  }
}
.static, .static *, .static *::before, .static *::after {
  animation: none !important;
  transition: none !important;
  scroll-behavior: auto !important;
}
```

### JS 側で使う道具(本体の `<script>` の先頭に 1 回だけ)
```js
const ROOT = document.documentElement;
const MOTION_OK = !ROOT.classList.contains('static');

// 日本時間の「今日」と「今の分」を返す(端末がどの国の時間設定でも日本時間で出す)
function tokyoNow(d = new Date()) {
  const p = {};
  new Intl.DateTimeFormat('en-US', {
    timeZone: 'Asia/Tokyo', year: 'numeric', month: '2-digit', day: '2-digit',
    weekday: 'short', hour: '2-digit', minute: '2-digit', hourCycle: 'h23'
  }).formatToParts(d).forEach(x => { p[x.type] = x.value; });
  return {
    date: `${p.year}-${p.month}-${p.day}`,                       // 例 "2026-11-13"
    wd: ['Sun','Mon','Tue','Wed','Thu','Fri','Sat'].indexOf(p.weekday), // 0=日
    min: p.hour * 60 + Number(p.minute)                          // 0〜1439
  };
}
```

- **対応状況**: `prefers-reduced-motion` Chrome 74 / Firefox 63 / Safari 10.1。`URLSearchParams` Chrome 49 / Firefox 29 / Safari 10.1。`Intl.DateTimeFormat` の `timeZone` Chrome 24 / Firefox 29 / Safari 10、`hourCycle` Chrome 73 / Firefox 58 / Safari 13、`formatToParts` Chrome 57 / Firefox 51 / Safari 11
- **対応しないとき**: `prefers-reduced-motion` を知らないブラウザでは「動く」側になる(止まらないだけで、見えなくなることはない)
- **注意**:
  - 隠す CSS は必ず `.js:not(.static) …` か `@media (prefers-reduced-motion: no-preference)` の中に書く。こうしておけば「JS なし」「動きを減らす設定」「?static=1」「JS エラー」の 4 つとも、最初から全部見える
  - `animation: none` にすると `transitionend` / `animationend` が来ない。終わりのイベントに頼る処理を書かない
  - `hourCycle: 'h23'` は、深夜 0 時が "24" と出る古い挙動を避けるため
  - スクロール連動(`animation-timeline`)は `animation-duration` を短くしても止まらない。必ず `@media (prefers-reduced-motion: no-preference)` で囲む(下のレシピはそう書いてある)

## レシピ

### 1. フェードイン(IntersectionObserver 版)
**逆引き**: 写真や文字がスクロールでふわっと出る(◎)

```html
<section class="fade">…</section>
```
```css
@media (prefers-reduced-motion: no-preference) {
  .js:not(.static) .fade {
    opacity: 0;
    transform: translateY(16px);
    transition: opacity .5s ease-out, transform .5s cubic-bezier(.2, .7, .2, 1);
  }
  .js:not(.static) .fade.in { opacity: 1; transform: none; }
}
```
```js
const fades = document.querySelectorAll('.fade');
if (MOTION_OK && 'IntersectionObserver' in window) {
  const io = new IntersectionObserver(entries => {
    entries.forEach(e => {
      if (e.isIntersecting) { e.target.classList.add('in'); io.unobserve(e.target); }
    });
  }, { rootMargin: '0px 0px -10% 0px' });
  fades.forEach(el => io.observe(el));
} else {
  fades.forEach(el => el.classList.add('in'));
}
```
- **対応状況**: IntersectionObserver は Chrome 51 / Firefox 55 / Safari 12.1(iOS 12.2)
- **対応しないとき**: `else` で全部 `.in` を付けるので見える。JS なしなら `.js` が付かないので最初から見える
- **注意**: ヒーロー(最初の画面)には付けない。1 画面に何個も付けない。移動は 10〜20px

### 2. フェードイン(CSS だけ、`animation-timeline: view()` 版)
**逆引き**: 同上(◎)

```css
@keyframes fade-up { from { opacity: 0; transform: translateY(16px); } }

@supports (animation-timeline: view()) {
  @media (prefers-reduced-motion: no-preference) {
    .fade-css {
      animation: fade-up linear both;
      animation-timeline: view();          /* animation の後に書く(省略形が上書きするため) */
      animation-range: entry 0% entry 60%;
    }
  }
}
```
- **対応状況**: `animation-timeline`(`view()`・`scroll()` とも)Chrome 115 / Firefox 159 / Safari 26。MDN では Baseline 2026(2026-10 に新しく全主要ブラウザ対応)
- **対応しないとき**: `@supports` の外なので何も起きず、最初から見えている
- **注意**:
  - `animation` の省略形は `animation-timeline` を `auto` に戻す。**`animation-timeline` は必ず後ろに書く**
  - スクロールを戻すと逆再生される(何度でも動く)。「1 回だけ出す」なら 1 の JS 版
  - 同じ要素に 1 と 2 を両方付けない
  - 古い iPhone(iOS 26 未満)ではただ表示されるだけ。2026-11 時点では 1 の JS 版を標準にし、2 は「JS を使いたくない飾り」に使う

### 3. 縮むヘッダー
**逆引き**: ヘッダーがスクロールで小さくなる・色が付く(○)。高さは変えず、背景と影だけ変える

```html
<div id="top-mark" aria-hidden="true" style="position:absolute;top:0;left:0;width:1px;height:80px"></div>
<header class="site-header">…</header>
```
```css
.site-header {
  position: sticky; top: 0; z-index: 40;
  background: #fff; box-shadow: 0 2px 8px rgb(0 0 0 / .08);   /* JS なしではこの見た目のまま */
  transition: background-color .2s, box-shadow .2s;
}
.js .site-header.at-top { background: transparent; box-shadow: none; }
```
```js
const header = document.querySelector('.site-header');
const mark = document.getElementById('top-mark');
if (header && mark && 'IntersectionObserver' in window) {
  new IntersectionObserver(([e]) => header.classList.toggle('at-top', e.isIntersecting)).observe(mark);
}
```
CSS だけで作る場合(対応ブラウザだけ):
```css
@keyframes header-solid { from { background: transparent; box-shadow: none; } }
@supports (animation-timeline: scroll()) {
  @media (prefers-reduced-motion: no-preference) {
    .site-header { animation: header-solid linear both; animation-timeline: scroll(); animation-range: 0 120px; }
  }
}
```
- **対応状況**: `position: sticky` Chrome 56 / Firefox 32 / Safari 13。IntersectionObserver は 1 と同じ。`scroll()` は 2 と同じ
- **対応しないとき**: いつも白い背景+影のヘッダーになる(読めなくなることはない)
- **注意**: 透明にするのは写真の上だけ。透明のときも文字のコントラストを測る。高さ・`padding` を変えると下の中身がずれるので変えない

### 4. ヘッドルーム型ヘッダー
**逆引き**: 下へスクロールで隠れ、上へ戻すと出る(○)

```css
.site-header { position: sticky; top: 0; z-index: 40; transition: transform .3s ease-out; }
.site-header.is-hidden { transform: translateY(-100%); }
.site-header:focus-within { transform: none; }   /* Tab で中のリンクに来たら必ず出す */
```
```js
(() => {
  const h = document.querySelector('.site-header');
  if (!h || !MOTION_OK) return;               // 動きを減らす設定では隠さない
  let last = scrollY, busy = false;
  addEventListener('scroll', () => {
    if (busy) return;
    busy = true;
    requestAnimationFrame(() => {
      const y = scrollY, dy = y - last;
      if (Math.abs(dy) > 8) {                  // 少し動いてから判定(小さな揺れで出入りさせない)
        h.classList.toggle('is-hidden', dy > 0 && y > h.offsetHeight * 2);
        last = y;
      }
      busy = false;
    });
  }, { passive: true });
})();
```
- **対応状況**: 基本の DOM と CSS だけ(全主要ブラウザ)
- **対応しないとき / JS なし**: いつも出ている普通の固定ヘッダー
- **注意**: 画面下の固定バー(13)は隠さない。ページ内リンクで下へ飛ぶとヘッダーが隠れるので、`scroll-margin-top`(9)は小さめでよい

### 5. スクロールスパイ
**逆引き**: 今読んでいる章を目次で光らせる(○)

```js
const tocLinks = [...document.querySelectorAll('.toc a[href^="#"]')];
const pairs = tocLinks
  .map(a => [document.getElementById(decodeURIComponent(a.hash.slice(1))), a])
  .filter(([sec]) => sec);
if (pairs.length && 'IntersectionObserver' in window) {
  const bySec = new Map(pairs);
  const io = new IntersectionObserver(entries => {
    entries.forEach(e => {
      if (!e.isIntersecting) return;
      tocLinks.forEach(a => a.removeAttribute('aria-current'));
      bySec.get(e.target).setAttribute('aria-current', 'true');
    });
  }, { rootMargin: '-45% 0px -50% 0px' });   // 画面のまん中の帯に入った章を「今」とする
  bySec.forEach((a, sec) => io.observe(sec));
}
```
```css
.toc a[aria-current] { font-weight: 700; box-shadow: inset 0 -2px 0 currentColor; }
```
- **対応状況**: IntersectionObserver(1 と同じ)
- **対応しないとき**: 光らないだけ。目次のリンクはそのまま使える
- **注意**: 色だけで示さない(太字・下線も付ける)。目次がない短いページには入れない

### 7. 押下フィードバック
**逆引き**: ボタンを押した感じを出す(◎)

```css
  background: var(--accent); color: #fff;
```

### 9. スムーズスクロール + scroll-margin
**逆引き**: ページ内リンクでなめらかに移動(◎)

```css
:root { --header-h: 64px; }
@media (prefers-reduced-motion: no-preference) {
  html { scroll-behavior: smooth; }
}
section[id], h2[id] { scroll-margin-top: calc(var(--header-h) + 12px); }
```
- **対応状況**: `scroll-behavior` Chrome 61 / Firefox 36 / Safari 15.4。`scroll-margin-top` Chrome 69 / Firefox 68 / Safari 14.1(iOS 14.5)
- **対応しないとき**: 一瞬で飛ぶだけ(位置は合う)。`scroll-margin-top` を知らない古い Safari では見出しがヘッダーの下に隠れる → 気になるなら `html { scroll-padding-top: … }` も足す(対応は同じ)
- **注意**: `?static=1` と動きを減らす設定では共通の土台が `auto` に戻す

### 10. アコーディオン(`<details>` をなめらかに開く)
**逆引き**: よくある質問がなめらかに開く(◎)/ FAQ アコーディオン(◎)

```html
<details class="faq">
  <summary>駐車場はありますか?</summary>
  <div class="faq-a"><p>お店の裏に 3 台あります。</p></div>
</details>
```
```css
.faq summary { cursor: pointer; padding: 14px 0; min-height: 44px; }
@supports (interpolate-size: allow-keywords) {
  @media (prefers-reduced-motion: no-preference) {
    :root { interpolate-size: allow-keywords; }
    .faq::details-content {
      block-size: 0; overflow: clip;
      transition: block-size .3s ease, content-visibility .3s allow-discrete;
    }
    .faq[open]::details-content { block-size: auto; }
  }
}
```
- **対応状況**:
  - `<details>` は全主要ブラウザ(JS なしで開け閉めできる)
  - `::details-content` Chrome 131 / Firefox 143 / Safari 18.4(Baseline 2025)
  - `interpolate-size` **Chrome 129 系だけ**(Firefox 未対応、Safari は Technology Preview のみ。MDN は「Limited availability・実験的」)
  - `content-visibility` Chrome 85 / Firefox 125 / Safari 18、`transition-behavior: allow-discrete` Chrome 117 / Firefox 129(一部)/ Safari 17.4
- **対応しないとき**: `@supports` で丸ごと外れるので、Safari・Firefox では一瞬で開くだけ。中身は必ず見える
- **注意**:
  - `@supports` を付けずに `::details-content { block-size: 0 }` だけ書くと、`interpolate-size` を知らないブラウザで「開いても高さ 0 のまま」になる恐れがある。**必ず `@supports (interpolate-size: allow-keywords)` の中に書く**
  - `<details name="faq">` で「1 つ開くと他が閉じる」にもできる(Chrome 120 / Firefox 130 / Safari 17.2)が、FAQ は見比べたいことが多いので付けない方がよい
  - 答えの中に予約ボタンを置いてよい。FAQ のリッチ表示は 2026-05 に終了(06 の B-3)

### 11. ビュー遷移(ページをまたぐ)
**逆引き**: ページを移るときになめらかに切り替わる(○)

```css
/* 移る前と後の両方のページに書く */
@media (prefers-reduced-motion: no-preference) {
  @view-transition { navigation: auto; }
}
::view-transition-old(root), ::view-transition-new(root) { animation-duration: .25s; }
html.static::view-transition-old(root), html.static::view-transition-new(root) { animation: none; }
```
- **対応状況**: `@view-transition`(ページをまたぐ)Chrome 126 / Safari 18.2 / **Firefox は preview だけ(未リリース)**。MDN は「Limited availability」。同じページ内の `document.startViewTransition()` は Chrome 111 / Firefox 144 / Safari 18
- **対応しないとき**: 普通にページが切り替わるだけ
- **注意**: 同じオリジン(同じドメイン)のページどうしだけ。1 ページのサイトでは不要。`?static=1` はリンク先に引き継がれないので、確認用スクショでは各ページの URL に付ける

### 12. 電話・LINE・地図リンク
**逆引き**: 押したら電話がかかる(◎)/ LINE ボタン(◎)/ 地図(◎)

```html
<!-- 電話: 国番号つき(+81、先頭の 0 を取る)。番号は文字でも見せる。制作例は 000-0000-0000 -->
<a class="btn" href="tel:+81312345678">電話する 03-1234-5678</a>
<small>受付 11:00〜20:00(火曜定休)</small>

<!-- LINE: @ を %40 にする。友だち追加(すでに友だちならトークが開く) -->
<a class="btn" href="https://line.me/R/ti/p/%40example">LINE で相談する</a>
<!-- LINE: 文を入れた状態でトークを開く(送信は本人が押す)。文は UTF-8 でパーセントエンコード -->
<a href="https://line.me/R/oaMessage/%40example/?%E4%BA%88%E7%B4%84%E3%81%AE%E7%9B%B8%E8%AB%87%E3%81%A7%E3%81%99%E3%80%82%E5%B8%8C%E6%9C%9B%E6%97%A5%3A">LINE で予約の相談をする</a>

<!-- 地図: API キー不要の Maps URLs。& は &amp; と書く -->
<a href="https://www.google.com/maps/search/?api=1&amp;query=%E3%80%87%E3%80%87%E5%B8%82%E3%80%87%E3%80%87%E7%94%BA1-2-3" target="_blank" rel="noopener">Google マップで開く</a>
<a href="https://www.google.com/maps/dir/?api=1&amp;destination=%E3%80%87%E3%80%87%E5%B8%82%E3%80%87%E3%80%87%E7%94%BA1-2-3" target="_blank" rel="noopener">ここまでの道順</a>
```
- **対応状況**: `tel:` はスマホで電話アプリ、PC では端末しだい(何も起きない・通話アプリが開く)。LINE の URL は LINE 公式ドキュメントの形(`ti/p/` `oaMessage/`)。PC で `ti/p/` を開くと Web のプロフィールか QR コードが出る。Maps URLs は `api=1` が必須、API キー不要、URL は 2,048 文字まで
- **対応しないとき**: PC で `tel:` が効かなくても、番号が文字で見えているので困らない
- **注意**:
  - 上の oaMessage の文は「予約の相談です。希望日:」をエンコードしたもの。文を変えたら `encodeURIComponent('…')` で作り直す
  - LINE ID のエンコードなしも動くが LINE は「非推奨」としている
  - iPhone は数字の並びを勝手に電話リンクにすることがある。値段や郵便番号が電話リンクになるなら `<meta name="format-detection" content="telephone=no">` を入れて、電話番号だけ自分で `tel:` にする

```js
    else if (c !== '\r') f += c;
  }
  if (f || row.length) { row.push(f); rows.push(row); }
  return rows;
```

```js
  el.hidden = false;
```

- **対応状況**: `navigator.share` Safari 12.1(iOS 12.2)/ Chrome Android 61 / PC の Chrome 128(127 までは Windows・ChromeOS だけ)/ **PC の Firefox はフラグのみ(実質未対応)**、Firefox Android 79。MDN は「Baseline ではない」。HTTPS が必要、ボタンを押したときにしか呼べない。`clipboard.writeText` Chrome 66 / Firefox 63 / Safari 13.1
- **対応しないとき**: リンクのコピーに切り替わる。それも駄目なら URL を表示して手でコピーしてもらう。JS なしではボタン自体が出ない
- **注意**: 共有したときの見え方は OGP(`og:title`・`og:image`)で決まる(#154)。GitHub Pages は HTTPS なので動く。`file://` やローカルの `http://` では `share` が無いことがある

### 24. reduced-motion の一括停止
**逆引き**: C-2「動きを減らす設定では止める」

共通の土台の CSS と `<head>` の script がこれにあたる。まとめると:
- **CSS**: `@media (prefers-reduced-motion: reduce)` と `.static` で `animation`・`transition`・`scroll-behavior` を全部止める
- **隠す CSS**: `.js:not(.static)` か `@media (prefers-reduced-motion: no-preference)` の中だけに書く
- **スクロール連動**(2・3 の CSS 版): `no-preference` の中だけに書く(時間を短くする止め方は効かない)
- **JS の動き**(4 のヘッドルームなど): `MOTION_OK` が false なら動かさない
- **ビュー遷移**: `@view-transition` を `no-preference` の中に書く(11)
- **確認**: macOS「システム設定 → アクセシビリティ → ディスプレイ → 視差効果を減らす」、iPhone「設定 → アクセシビリティ → 動作 → 視差効果を減らす」、Chrome の開発者ツール「Rendering → Emulate CSS media feature prefers-reduced-motion」。`?static=1` でも同じ見た目になるか見る

## 独自ドメインと HTTPS

### GitHub Pages に独自ドメインを付ける手順(GitHub 公式)
1. **先に GitHub 側で登録**: リポジトリの Settings → Pages → Custom domain にドメインを入れて Save(DNS を先に設定すると、他人にそのドメインでサイトを出される恐れがあるため、この順番)
2. **ドメインの確認(verify)をしておく**(乗っ取り対策として推奨)
3. ドメイン会社が最初に作った不要なレコードを消す
4. DNS レコードを作る
   - 素のドメイン(`example.com`): **A レコード** `185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153`(IPv6 も使うなら AAAA `2606:50c0:8000::153` / `2606:50c0:8001::153` / `2606:50c0:8002::153` / `2606:50c0:8003::153`)
   - `www.example.com`: **CNAME** を `mnt22914-a11y.github.io`(リポジトリ名は入れない)に向ける。両方設定すると GitHub が自動で片方へ転送する
   - **`*.example.com` のようなワイルドカードは作らない**(乗っ取りの危険)
5. `dig example.com +noall +answer -t A` で 4 つの IP が出るか確認(反映は最大 24 時間)
6. **Enforce HTTPS** にチェック。証明書は GitHub が Let's Encrypt から自動で取る。時間がかかって終わらないときは、ドメインを Remove → もう一度入れて Save
- 余計な A / AAAA / ALIAS / CNAME があると証明書が出ない
- `http://` の写真やファイルを読んでいると「混在コンテンツ」になる → 全部 `https://` か相対パスにする
- 注意: noren-works は 1 つのリポジトリに作品が並ぶ形。**お客さんのサイトを独自ドメインで出すなら、1 店 = 1 リポジトリ**(独自ドメインはリポジトリごとに 1 つ)

**おすすめ**: 内閣府 CSV から今年と来年の分だけ取り出し、`index.html` の `HOLIDAYS` に直接書く(外部読み込みなし・止まらない)。毎年 2 月(翌年の祝日が出たら)に更新する作業を予定に入れる。

変換用(代表のパソコンで実行。出てきた 1 行を `HOLIDAYS` に貼る):
```bash
python3 - <<'EOF'
import csv, io, json, urllib.request
raw = urllib.request.urlopen('https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv').read().decode('cp932')
days = []
for row in list(csv.reader(io.StringIO(raw)))[1:]:
    if len(row) < 2 or not row[0]:
        continue
    y, m, d = row[0].split('/')
    key = f"{y}-{int(m):02d}-{int(d):02d}"
    if key >= '2026-01-01':
        days.append(key)
print('const HOLIDAYS = new Set(' + json.dumps(days) + ');')
EOF
```
- お店独自の休み(お盆・年末年始・臨時休業)は祝日とは別に `closed`(14 のデータ)で持つ。「祝日は営業・翌日休み」の店は `HOURS.holiday` と `closed` で表す
