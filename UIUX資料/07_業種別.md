# 業種別の UX

調べた日: 2026-11-13 / 対象: 日本の小さな店舗(個人経営)のホームページ
`UIUXスキル表.md` と `05_中身と成約.md` にある「業種を問わない決まり」(税込総額・ステマ規制・医療/あはき/柔整/化粧品/エステの広告規制の基本)は繰り返さない。ここでは**業種ごとの違い**だけを書く。

- 根拠の強さ: **A** = 法令・官公庁・一次調査 / **B** = 業界・大手ポータルの調査 / **C** = 慣習・ブログ・制作側の経験則
- 数字は出典で確かめたものだけ。確かめられないものは「未確認」と書いた。

## 3 行の要点

1. **美容系(美容室・ネイル・エステ)は「近さ・値段・ネットの口コミ」で選ばれ、ネット予約が主流**。美容室の女性はネット予約 55.7%・電話 23.6%(2024)、ネイルはネット予約 74.8%(2023)。続けて通う理由の 1 位も「ネット予約できる」。予約ボタンを最優先に置く(B)。
2. **ジム・塾・エステ・美容医療は「契約」で揉める業種**。パーソナルトレーニングの相談は 2021 年度 495 件 → 2025 年度 1,457 件。不安は「勧誘・解約・総額」なので、**総額・解約の条件・体験後に勧誘するかどうかを料金ページに書く**のがいちばん効く(A)。塾・エステ・美容医療は特商法の「特定継続的役務」なので、中途解約の決まりも書く(A)。
3. **飲食はアレルギー・酒・たばこ、整体はことば選びに法律がからむ**。外食のアレルギー表示は義務ではないが、書くなら「混入の可能性」を必ず書く(業界の手引き)。喫煙できる店は入口に標識が要る。無資格の整体は「腰痛」「肩こり」への施術や「マッサージ」という言葉を Web にも書かない(2025 年の厚労省の指針)(A)。

## 業種ごと

### ジム(24 時間・パーソナル・シニア向け)
- **探される情報(順に)**: ① 月額・総額(入会金・事務手数料・水光熱費などの追加を含む)② 解約・休会の方法と縛り ③ 場所と営業時間(24 時間か・スタッフがいる時間)④ 混み具合 ⑤ マシン・設備 ⑥ 体験の内容。※順位を示す国内の一次調査は見つからなかった(未確認)。オリコン顧客満足度調査の評価項目は「入会手続き・プラン・コスパ・衛生・施設・インストラクター・サポート・通いやすさ」(B)
- **来店前の不安と消し方**
  - **勧誘**: 相談の典型は「SNS 広告 → 無料体験 → 長時間のカウンセリング → 今日なら割引」。約 1 時間の体験のあと約 2 時間勧誘された事例もある [1]。→ 体験の流れと所要時間を書き、「体験当日に契約を求めません」「持ち帰って検討できます」と書けるなら書く(書いたら守る)
  - **解約**: 「解約料が高い」「解約したのに引き落としが続く」「アプリ型ジムで電話がつながらず解約できない」[1][2]。→ 解約の方法(店頭・Web・電話)、何日前までに、休会の有無と費用、自動更新の有無を料金表のすぐ下に
  - **総額と効果**: 「○kg 痩せると言われたが痩せなかった」相談もある [1]。→ 効果を約束しない。コースの総額・回数・期間・有効期限を 1 つの表に
  - **パーソナル特有**: 「予約が取れない」「トレーナーが変わる」[1]。→ 予約の取り方、変更・キャンセルの期限、担当変更の可否を書く
  - **混雑(24 時間)**: 混雑の時間帯、無人時間帯の防犯(カメラ・入館方法)。大手の chocoZAP はトップで「月額 2,980 円[税込 3,278 円]」と出し、「24 時間ではない店舗・休館日のある店舗がある」と注記し、店舗の状況が分かるページへのリンクを置いている [16]
  - **シニア向け**: 付き添い・体力の目安・送迎・医師の許可が要るか・更衣室やトイレの段差。※根拠となる調査は未確認(C)
- **定番の構成 / 特有の部品**: 料金プラン比較表(税込・総額・期間・回数)/ 入会から利用開始までのステップ / 体験予約 / マシン・設備一覧(写真つき)/ 混雑の目安(時間帯グラフ)/ トレーナー紹介(資格は事実だけ)/ よくある質問(解約・休会・持ち物)/ 女性専用・初心者向けの説明
- **予約・問い合わせ**: 体験はネット予約か LINE。シニア向けは電話を主に(C)
- **法規制・書いてはいけないこと**
  - ジム・パーソナルトレーニングは特商法の「特定継続的役務」の 7 類型に**入っていない** [3]。そのため法律上のクーリング・オフは通常ない(報道では国民生活センターが「一般的に対象外」と説明。原文では未確認)。だからこそ、店の解約ルールを自分で明示することが信頼になる
  - **ジムと一緒に痩身エステを売るなら**、そのエステ契約(1 か月超・5 万円超)は特定継続的役務になりうる [1][3]
  - 「今日だけ」「残り○枠」を偽らない、実績のない「通常価格」を書かない(スキル表 #121)
  - 痩身・ダイエットの効果を断定しない(優良誤認)。サプリを売るなら健康食品・薬機法の表現にも注意(スキル表 #126)
- **根拠**: [1] A・[2] A・[3] A・[16] C(実例)

### 居酒屋
- **探される情報(順に)**: ① 料理と値段(コース・飲み放題の総額)② 席(個室・座敷・人数・貸切)③ 場所・営業時間・ラストオーダー ④ 予約の空き ⑤ 喫煙か禁煙か。※首都圏 2,106 人の調査で、また行く店を選ぶ理由は「料理がおいしい」69.6%・「コスパ」48.6%・「席がゆったり」40.4%・「アクセス」40.2%・「価格が明示されている・会計がわかりやすい」34.4%(2019 年、外食全般)[9] B
- **来店前の不安と消し方**: 「会計がいくらになるか」(お通し・席料・サービス料の有無)、「何人入れるか・個室か」、「たばこ」、「団体で騒がしいか」。→ お通し代を含めた目安、コースの税込総額と飲み放題の時間・ラストオーダー、席の写真と人数、喫煙の扱いを書く
- **定番の構成 / 特有の部品**: 看板料理の写真 / お品書き(税込)/ コース・飲み放題の表 / 席の種類と最大人数 / 貸切の条件(人数・最低金額)/ 宴会の予約フォーム / 喫煙の扱い / アレルギーの問い合わせ先
- **予約・問い合わせ**: 当日・少人数は電話、宴会はネット予約かフォーム(C)。店側の調査では、最多の予約経路はまだ電話(飲食店ドットコム、2024 年。本文未読のため数字は未確認)
- **法規制・書いてはいけないこと**
  - **たばこ**: 2020 年 4 月から飲食店は原則屋内禁煙。喫煙室は「喫煙専用室」「加熱式たばこ専用喫煙室」「喫煙可能室」の 3 種類で、**入口などに標識を掲げる義務**がある。喫煙エリアに 20 歳未満は入れない [14]。Web への表示義務は見つからなかったが、喫煙可の店は「20 歳未満は入店不可」になりうるので、家族客向けにサイトでも書いておく(C)
  - **アレルギー**: 飲食店で出す料理は食品表示法のアレルギー表示の**義務の対象外**。ただし容器に入れて売るもの(テイクアウトの包装品など)は対象 [12][13]。書くなら「混入の可能性」を必ず書く(下の「カフェ・パン屋」も参照)[11]
  - **酒の通販**: 店で酒を量り売り・通販するなら免許が要り、広告・申込画面に「20 歳未満の者の飲酒は法律で禁止されている」などの表示が要る [15]。ふつうに店内で出すだけなら Web の表示義務は見つからなかった
  - 飲み放題・宴会の「1 名○円〜」は、何が含まれるかと条件を近くに書く(有利誤認を避ける。スキル表 #121)
- **根拠**: [9] B・[11] B・[12] A・[13] A・[14] A・[15] A

### カフェ
- **探される情報(順に)**: ① 雰囲気(店内写真)② メニューと値段 ③ 営業時間・定休日 ④ 席・混み具合・滞在時間の制限 ⑤ Wi-Fi・電源・作業してよいか ⑥ 子連れ・ペット可か。※喫茶店・カフェは「その店に行きたくて行く」目的型来店の割合が 52.0%(25 業態中 3 位)、リピート利用は 83.8%(2019 年)[9] B。④〜⑥の順位は未確認(C)
- **来店前の不安と消し方**: 「座れるか」「長居してよいか」「作業してよいか」「子どもを連れて行ってよいか」。→ 席数、混む時間、時間制限の有無、PC 作業・Wi-Fi・電源、ベビーカー・子ども椅子の有無をアイコンつきの一覧で
- **定番の構成 / 特有の部品**: 店内の写真(席ごと)/ メニュー(ドリンク・フード・季節限定)/ 「設備・ルール」の一覧(Wi-Fi・電源・禁煙・子連れ・ペット)/ 混雑の目安 / テイクアウト・焼き菓子 / Instagram への導線
- **予約・問い合わせ**: 予約なしが基本。予約を受けるなら電話か LINE(C)
- **法規制**: アレルギーは居酒屋と同じ(店内で出す料理は義務外、包装品は対象)[12][13]。たばこの標識 [14]。焼き菓子を通販するならパン屋・菓子店の欄を見る
- **根拠**: [9] B・[12] A・[13] A・[14] A

### ラーメン店
- **探される情報(順に)**: ① 一杯の写真と味の系統 ② 値段とトッピング ③ 営業時間(スープ切れで終わるか)・定休日 ④ 行列・待ち時間 ⑤ 注文の仕方(券売機・現金のみか)⑥ 駐車場。※「立ち食いのラーメン、うどん・そば業態」のリピート利用は 92.9%、「ラーメン・そば・うどん・パスタ・ピザなどの専業店」の目的型来店は 51.9%(2019 年)[9] B。①〜⑥の順位は未確認(C)
- **来店前の不安と消し方**: 「並ぶか」「注文の作法がわからない」「現金しか使えないか」「一人で入りやすいか」「子連れ・少食でも大丈夫か」。→ 混む時間、券売機の写真と手順、支払い方法、ミニサイズ・子ども用の有無、席(カウンター数・テーブル)
- **定番の構成 / 特有の部品**: 看板の一杯を大きく / メニュー(麺の固さ・味の濃さ・替玉など注文の選び方)/ 「初めての方へ」(入店 → 食券 → 着席 → 注文)/ 営業状況(スープ切れ・臨時休業)を SNS や Google マップと合わせる / 行列のルール(近隣への配慮)/ 外国語メニュー。実例: 一蘭は「初めてのご来店」ページで利用の流れを動画(日本語・多言語の字幕つき)で見せている [17]
- **予約・問い合わせ**: 予約なしが基本。営業状況の発信は SNS(C)
- **法規制**: アレルギー(小麦・卵・えび・かになど)は義務外だが、聞かれたときの答え方を決め、書くなら混入の注意を併記 [11][12]。たばこの標識 [14]
- **根拠**: [9] B・[11] B・[12] A・[14] A・[17] C(実例)

### 美容室
- **探される情報(順に)**: 2024 年の美容センサス(全国 20 万人以上の都市の 15〜69 歳、男女各 6,600 人)で、女性が初めての店を選ぶとき重視したのは「自宅から近い」34.6%・「料金がリーズナブル」31.1%。10〜30 代は「ネットの口コミが良い」、40〜60 代は「自宅から近い」が 1 位。男性は「自宅から近い」24.7%・「友人・知人の口コミが良い」22.7% [5] B。2015 年の調査では女性の 4 位が「料金が明確だった」22.0% [6] B
  → サイトでは ① スタイル写真 ② メニューと税込料金 ③ 場所・アクセス ④ スタッフ ⑤ 予約の空き の順に出す
- **来店前の不安と消し方**: 「担当は誰か・どんな人か」「仕上がりがイメージ通りになるか」「総額がいくらか(ロング料金・指名料・トリートメント追加)」「混んでいて予約が取れるか」。→ スタッフごとの得意なスタイルと写真、料金表に追加料金の条件を全部書く、所要時間を書く
- **定番の構成 / 特有の部品**: スタイル写真のギャラリー(長さ・メニュー別で絞り込み)/ スタッフ紹介と指名 / メニュー表(税込・追加料金・所要時間)/ 初回の流れ(カウンセリング)/ ネット予約ボタン(スタッフ・メニュー・日時で選ぶ)/ 使う薬剤・商品
- **予約・問い合わせ**: **ネット予約が主流**。女性はネット予約 55.7%(20 代 71.9%・30 代 70.1%)、電話 23.6%(年々減少)。ネット予約の中では予約サイト・アプリ(ホットペッパービューティーなど)が 42.5% で最多 [5] B。今通う店を続ける理由の 1 位も「ネット予約できる」(女性 32.5%・男性 33.6%)[5] B。→ ポータルの予約ページへのボタンを最優先で置き、50〜60 代向けに電話も残す
- **法規制・書いてはいけないこと**: 美容室に特有の広告規制は見つからなかった(未確認)。一般の決まり(税込総額・「〜円から」の条件・ステマ規制)を守る。店で売るシャンプーなどは化粧品の効能の範囲だけ(スキル表 #126)。縮毛矯正・白髪染めで「髪が修復する」「白髪が治る」などは書かない(C)
- **根拠**: [5] B・[6] B

### 整体・接骨院・鍼灸
- **探される情報(順に)**: ① どんな症状・悩みに対応するか(ただし書き方に強い制限あり)② 料金(保険か自費か・回数券)③ 施術の流れ・時間・痛くないか ④ 施術者(資格)⑤ 予約・営業時間(夜・土日)⑥ 駐車場。※順位を示す調査は未確認(C)
- **来店前の不安と消し方**: 「痛くないか」「何回通わされるか」「回数券を売りつけられないか」「保険が使えるか」「国家資格者か」。→ 1 回の料金と回数券の中身・有効期限・返金、施術の流れ、資格の種類(国家資格か民間か)をはっきり書く
- **定番の構成 / 特有の部品**: 料金表(初回・2 回目以降・回数券)/ 施術の流れ / 施術者の紹介 / 予約(時間帯)/ 院内の写真 / 駐車場 / アクセス
- **予約・問い合わせ**: 電話と LINE が中心、ネット予約を足す(C)
- **法規制・書いてはいけないこと**(2025 年 2 月 18 日の厚労省の指針 [4] A)
  - Web サイトは原則「広告」とは見なされない。ただし指針は Web の「載せるべきこと」と「載せるべきでないこと」を決めている。リスティング広告や料金を払って上位に出すものは広告として扱う
  - **載せるべきこと**: 問い合わせ先 / 自費の施術の内容と通常かかる費用 / 回数券・プリペイドを売るなら中身と契約内容 / 自費の施術の主なリスク・副作用
  - **載せるべきでないこと**: 「絶対安全」「絶対に治る」/ **加工・修正した施術前後の写真** / 「口コミサイトで 1 位」「○○に掲載された」など他との比較 / 誇大な表現 / 早く受けるよう過度にあおる表現・費用の安さの過度な強調 / 根拠の乏しい情報で不安をあおる表現
  - **保険の書き方**(看板・チラシなど広告の場合): 「各種保険取扱い」「交通事故取扱い」「労災・自賠責取扱い」は**広告できない**。書けるのは「医療保険療養費支給申請ができる旨」で、あはきは医師の同意が要る旨、柔整は骨折・脱臼の施術に医師の同意が要る旨を書く場合に限る。言い換え例「医療保険により施術費用の一部負担で施術を受けることができます」は可
  - 「予約優先」「メールで予約を受け付けています」、休日・夜間の施術は広告できる
  - **無資格の整体・リラク**: 国家資格の業(あん摩マッサージ指圧など)と誤解させる表示は不適切。**「マッサージ」という言葉を使わない**。**「腰痛」「膝の痛み」への施術、慢性の「肩こり・疲労」への施術という表現は、広告にも Web サイトにも書くべきでない** [4]
- **根拠**: [4] A。既存の決まり(スキル表 #124〜125)も参照

### ネイル・エステ
- **探される情報(順に)**
  - ネイル: 女性が初めての店を選ぶとき重視したのは「ネットの口コミが良い」31.8%・「料金がリーズナブル」19.6%・「友人・知人の口コミが良い」19.4%。男性は「ネットの口コミが良い」24.2%・「ネットに掲載されているデザインやスタイルが良い」23.8%(2023 年)[7] B → デザイン写真・料金・口コミへの導線
  - エステ(脱毛): 女性は「ネットの口コミが良い」33.1%・「友人・知人の口コミ」20.6%・「料金がリーズナブル」17.9%・「ネット予約できる」13.3%・「料金が明確」12.6%・「女性の施術者がいる」9.9%。男性は 4 位に「ネットに掲載されている情報で自分に合いそうなスタッフを見つけられる」13.8%(2022 年)[8] B
- **来店前の不安と消し方**: 「総額(オフ代・持ち込みデザイン代・追加パーツ)」「勧誘されないか」「コースの解約」「施術者が同性か」「痛み・肌トラブル」。→ 料金表にオプションを全部、勧誘の方針、コースの解約条件、施術者の性別、衛生対策
- **定番の構成 / 特有の部品**: デザイン写真(定額デザインの一覧・月替わり)/ 料金表(オフ・長さ出し・パーツ)/ スタッフ紹介 / 衛生対策 / 予約ボタン / コース・回数券の説明 / 解約・返金の説明
- **予約・問い合わせ**: **ネット予約が圧倒的**。ネイルは女性 74.8%・男性 54.0% がネット予約(2023 年)[7]。脱毛エステも女性 69.1%・男性 54.3%(2022 年)[8]。続ける理由の 1 位も「ネット予約できる」(ネイル女性 39.7%、脱毛女性 36.2%)[7][8] B
- **法規制・書いてはいけないこと**

## 未確認・意見が割れていること

- **飲食店のサイトで見られる情報の順位**: 国内の消費者調査で「サイトで何を見るか」の順位を示すものは見つからなかった。使えたのは 2019 年の「リピートする店の重視点」だけ [9]。ぐるなび・食べログの消費者調査は今回見つけられなかった
- **飲食店の予約経路の割合**: 店側の調査で「最多は電話」(飲食店ドットコム 2024)、消費者側で「ネット利用 69.3%」(民間の 329 人調査)という記事があるが、本文を確かめていない。営業で数字を使わない
- **ジム・整体・歯科・パン屋・塾の「探される情報の順位」**: 業界団体や官公庁の調査は見つからなかった。上の順位は制作側の判断(C)
- **パーソナルトレーニングのクーリング・オフ**: 「一般的に対象外」は報道の説明。国民生活センターの原文には「関連サービスが特定継続的役務にあたればクーリング・オフを主張できる可能性」とだけある [1]。法定の 7 類型に入っていないこと自体は消費者庁のページで確認 [3]
- **パーソナルの 1,457 件の範囲**: 報道で「美容目的のパーソナルトレーニング」とするものと「パーソナルトレーニング全体」とするものがある。国民生活センターの図は「パーソナルトレーニング」の相談件数としている [1]
- **美容室の最新データ**: 2025 年版の美容室の詳細版は見つからなかった(2024 年版を使用)。「2025 年のネット予約 59.2%」は二次情報だけで未確認
- **通販する菓子・パンの表示**: 製造小売の免除が通販に及ぶかは未確認。保健所に確認する
- **酒の通販の表示**: 国税庁の告示・手引の本文は開いておらず、検索結果の要約で確認した段階 [15]。酒を通販するときは原文を読む
- **外食のアレルギー情報の手引き**: 手元の版(2023 年 3 月修正)は「義務 7 品目・推奨 21 品目」と書いてあり、2026 年 4 月時点の品目(義務 9・推奨 20+ピスタチオ)と合わない。手引きの考え方(混入の注意は必ず書く)は使い、品目は消費者庁の最新に合わせる [11][12]
- **喫煙の扱いを Web に書く義務**: 見つからなかった。入口の標識の義務だけを確認 [14]
- **良い実例サイト**: 今回 URL を確認できたのは大手の 2 件(chocoZAP・一蘭)だけ。個人店の良い実例は未調査
