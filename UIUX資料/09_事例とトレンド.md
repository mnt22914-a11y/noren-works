# 実例・トレンド・AI っぽさの避け方

調べた日: 2026-11-13。担当: 実例・トレンド・AI っぽさ・写真の方向づけ。
`UIUXスキル表.md` と `02_見た目のデザイン.md`(02-57・58 の AI っぽさ、#72〜79 の写真)と重なる所は番号だけ書き、ここでは**その先**を書く。
根拠の強さ: **A** = 研究・一次資料(公式の説明を含む)/ **B** = 業界の調査・大手のレポート / **C** = ブログ・観察(ここでの自分の集計も C)。

## 3 行の要点
1. **「型」はいじらず、「中身」で個性を出す。** 見慣れた形のサイトが好かれる(Tuch 2012、スキル表 #9)。AI っぽさは「中央寄せ+同じカード 3 枚+紫グラデ+Inter」のように**中身まで平均的**なときに出る。直すのは配置ではなく、色・書体・写真・言葉を店の実物から取ること。
2. **ギャラリーに載る店舗サイトは「有料書体+動画+和の罫線・縦書き」が多いが、そのまま真似できない。** 41 の店舗サイトを見たところ、飲食 22 件のうち 16 件で動画が使われ、9 件が Adobe Fonts(有料)を読んでいた。ノレンは Google Fonts だけ・1 ファイルなので、**取り入れるのは「静かな部分」(配色・明朝と欧文セリフの組み合わせ・縦書きの見出し・罫線・紙の質感)**。
3. **写真は「暗い・きれいすぎる・正面で左右対称」が一番損をする。** 本物はスマホでよく、窓際の半逆光で寄って撮る。AI で作るなら「完璧」「8k」のような言葉を外し、光の向き・時間・不完全さを具体的に書き、看板の文字と手元は写さない。実在の店で料理を AI 画像にするのは、実物と違えば景品表示法の優良誤認にあたるおそれがある。

**表の読み方の注意**
- ギャラリーは「よくできたサイト」を集める場所なので、制作会社が手がけた予算の大きいサイトに寄る。**普通の個人店のサイトの平均ではない。**

- 有料書体(Adobe Fonts の Source Han Serif・DNP 秀英・FOT セザンヌなど)の印象は、Google Fonts の近い書体で置き換える(下の「書体の組み合わせ」)。

## 2025〜2026 のトレンド(表: トレンド・中身・店舗サイトに向くか・理由)

出どころ: Figma の「2026 年の Web デザイントレンド」13 項目+AI 3 項目 [7]、海外のデザイン・トレンド記事 [8][9][10]、国内の記事 [11][12]、Pantone [13]。**どれも「選んだ人の見立て」で、どれだけ使われているかを測った調査ではない**(Figma のページも測定ではない)。

| トレンド | 中身 | 店舗サイトに向くか | 理由 |
|---|---|---|---|
| 手触り・不完全さ(手描き・紙・コラージュ) | AI が作るつるつるした見た目への反動。手描きの線、紙の質感、切り抜き。「Anti-AI Crafting」とも [7][9][10] | ○ 少しだけ | 店主の手書きの品書き・スタンプ・紙の地は「人が作った店」に見える。ただし文字を画像にしない(#75)。量を増やすとマキシマリズムになる |
| 白を主役に(Pantone 2026 = Cloud Dancer) | 2026 年の色は白(11-4201)。白が選ばれたのは 1999 年の開始以来はじめて [13] | ○ | 写真が主役の店舗サイトと合う。ただし真っ白より、生成り・紙の白の方が「店の実物」に近い |
| 大胆な文字(画面いっぱいの見出し) | 巨大な見出し、可変フォント [7][8] | △ | 店名・一言を大きくするのはよい。画面を文字で埋めて写真と情報が 2 画面目に落ちると、#10・#11 に反する |
| 縦書き・罫線(国内ギャラリー) | MUUUUU で縦書き 168 件、罫線 675 件のタグ。飲食 96 件中、縦書き 15、罫線 19 [4] | ○ 見出しだけ | 和の業種に合い、テンプレ感を減らす。本文は横書き(#27) |
| 鮮やかな配色・ネオン・グラデーション | 高彩度、ネオンのグラデーション、ドーパミンカラー [7][11] | △ | アクセント 1 色(#34)なら効く。グラデーションは AI っぽさの代表(02-57) |
| 3D・没入型(WebGL) | 3D モデル、スクロールに合わせた演出。Awwwards の日替わり賞で 3D が 61% という記事もある(1 社の集計) [8] | ✕ | 重い・1 ファイルに収まらない・動きを止められない。店のお客さんの目的(#1)と関係ない |
| モーション・スクロールの物語 | 細かい反応、スクロールに合わせた演出 [7][12] | △ 押した反応だけ | 押した時の 0.1 秒の反応(#56)は必要。スクロールを乗っ取る演出は ✕(#85) |
| 実験的なメニュー(円形・隠しドロワー) | 「ホーム / 店について / 連絡先」から外れた導線 [7] | ✕ | 見慣れた形が好かれる(#9)。隠すと使われない(#61) |
| ダークモード | 暗い背景、明暗の切り替え [7] | △ バー・焼肉などの夜の店だけ | 初期は明るい背景(#37)。暗い地は文字のコントラストを必ず測る(#31) |
| すりガラス・Liquid Glass | Apple の Liquid Glass(2025-06 発表)、Material 3 Expressive [12] | ✕ | 背景によって文字が読めなくなる。すりガラスは AI っぽさの特徴にも挙がる(02-57) |
| ネオブルータリズム | 太い枠線・硬い影・素の構造 [7][8] | △ ジム・古着など一部 | 強い個性の店には合う。年配の客が多い業種には合わない |
| ニューモーフィズム | 柔らかい影で浮き出た立体 [7] | ✕ | ボタンの枠が背景と 3:1 にならない(#32) |
| マキシマリズム・レトロフューチャー・Y2K | 情報を重ね、ネオン・クロム・ピクセル [7] | ✕(喫茶・駄菓子のレトロなら別) | 情報が埋もれる(#43) |

## AI っぽい・テンプレっぽいデザインの特徴と避け方(表)

02-57・58 に書いた「紫のグラデーション・Inter・中央寄せ・小さなバッジ・同じカード 3 枚・数字の帯・すりガラス」の一覧の先として、**なぜそうなるか**と**日本語のサイトで出やすい形**を足す。

**なぜ似るか(C)**: 指示があいまいだと、モデルは学習データの平均で空白を埋める。紫は Tailwind UI が既定で使っていた `indigo-500` が Web に広まった影響だ、という指摘がある [14]。「AI っぽくなくして」とだけ頼むと、別の定番に寄る(02-58)。

| 特徴 | どう見えるか | 避け方 | 根拠 |
|---|---|---|---|
| 3D 風・絵文字のカラフルなアイコン | 何も指定しないと、見出しや特徴にキラキラしたアイコンが入る。子どもっぽく安く見える | アイコンは線画で 1 種類にそろえる。店舗サイトならアイコンより小さな写真か、文字だけ(#58) | C [15][16] |
| 中央寄せのカード 3 枚が、同じ高さ・同じ影で並ぶ | 整いすぎてテンプレに見える。どれも同じ重さで、優先順位がない | 一番伝えたい 1 つを大きく、残りを小さく。カードをやめ、写真+短い文の左右交互にする。囲みは操作できる物だけ | C [14][15][16] |
| カードの中にカード、全部を枠で囲む | 何段も入れ子になり、どれが大事か分からない | 余白・近さ・文字の大きさでまとめる(#41) | C [16] |
| 色が多い・ネオンの色を 5〜6 色同時に | どれも目立とうとする | 主色・アクセント・中間色の 3 色+文字と背景。アクセントは押してほしい物だけ(#34) | C [15][16] |
| 理由のない光彩・オーロラ背景の暗い画面 | ヒーローの後ろがぼんやり光る | 暗い地にするなら面の明るさの差で奥行きを出し、光の飾りは消す | C [16] |
| 左端に色の違う縦線、意味のない色の丸 | ブロックごとに赤・青・緑の線や丸 | 色の意味を先に決める。意味がない飾りは消す | C [16] |
| どの店にも言えるキャッチ | 「こだわりの〜」「心を込めて」「あなたらしく」のように、店名を替えても通じる。英語圏では「In today's fast-paced world」型 | 店にしかない事実を書く(創業年・席数・仕入れ先・店主の名前・駐車台数) | C [17](日本語の例は観察) |
| 根拠のない数字の帯・実績の欠如 | 「満足度 98%」「1,000 人以上」など。または逆に、本物の写真や数字が 1 つもない | 確かめられる数字だけ。お客様の声は載せない(ノレンのルール)。代わりに店の実物の写真 | C [17] |
| 和文に欧文書体だけを指定 | Inter や Roboto だけ書くと、日本語は端末の標準書体になり、見た目が端末ごとにばらばら | 和文書体を必ず指定し、欧文書体を先、和文書体を後に並べる(#28) | C [15] |
| 書体が 3 種類以上、角丸・影・グラデーションが同時に主張 | 装飾が多い | 書体 2 つ(#22)。角丸・影・グラデーションは上限を数値で決める(角丸は 1 種類、影は 1 種類) | C [15] |
| 目的のない動き | 何にでもフェードイン、反応しないホバー | 動きは「押した反応」と「開閉」だけ(#80〜87) | C [14][17] |
| つるつるの AI 画像・看板の文字の崩れ | 下の「AI 生成画像」の表を参照 | 本物の写真を最優先(#72) | C [17] |
| 汎用の alt・OG 画像なし・説明文の重複 | 共有したときに「作りっぱなし」に見える | alt は写っている物(#78)、OG 画像は店の写真 | C [17] |

**避け方の進め方(ノレン向けにまとめたもの)**
1. **型は変えない。** ロゴ左上・メニュー右上・上から下へ(#46)。見慣れた形が好かれるのは研究で確かめられている(#9)。奇抜な配置で AI っぽさを消そうとしない。
2. **先に「店の実物」を 3 つ決める**: 写真 1 枚(看板メニューか店内)、色 1 つ(のれん・看板・器・制服)、書体の方向 1 つ(看板やメニュー表の文字が明朝か、ゴシックか、手書きか)。
3. **AI に作らせるときは「禁止事項」と「参考」を両方渡す**: 参考サイトの URL を 3〜5 件、特徴を言葉にしたもの、使わない物(紫のグラデーション・Inter だけ・絵文字のアイコン・カード 3 枚並び・すりガラス)。目的と、来てほしいお客さんを最初に書く [14][15]。
4. **3 つの違う方向を出させて選ぶ。** 1 案だと平均に寄る [14]。
5. **最後に、店名を別の店に替えても通じる所を探して消す**(キャッチ・強み 3 つ・写真)。

## AI 生成画像を自然に見せる方法(表)

**前提**
- 「指を数える」「文字の崩れを探す」だけでは、もう見分けられない。2023 年の Midjourney の更新から手の破綻は減った [18]。研究(Kamali ら 2024、生成画像 138 枚と実写 42 枚)は、不自然さを「解剖学的・様式的・機能的・物理法則・社会文化的」の 5 つに分けている [19][20]。**作る側から見ると、この 5 つを出さない指示を書けばよい。**
- AI 広告と実写の広告を比べた実験(2,593 人)では、見分ける一番の手がかりは個別の破綻より「全体の違和感」だったという [18]。
- **実在の店の料理や商品を AI 画像で出すのは避ける。** 実物と大きさ・材料・見た目が違えば、景品表示法の優良誤認にあたるおそれがある [21][22]。米国では AI の料理写真を使った飲食店が SNS で批判され、Walmart は 2026-09 に店舗で AI ツールの看板を出すのを禁じた(報道の要約)[22]。ノレンの架空店の制作例では使ってよいが、実在の店では**店内・料理は本物の写真**、AI は背景の質感や季節の飾りまで。

| 出やすい不自然さ | 例 | プロンプトの工夫 | 後で確かめること | 根拠 |
|---|---|---|---|---|
| つるつる・プラスチックの質感 | 料理がろう細工、肌に毛穴がない、全部にピントが合う | 「perfect」「flawless」「beautiful」「8k」「masterpiece」「hyper-detailed」を**書かない**。表面の質感を具体的に(「パルメザンが不揃いに散る」「バジルが少ししおれる」「パンの断面の不揃いな気泡」) | 拡大して質感を見る | C [23][24] |
| 光が平らで、向きが合わない | どこから光が来ているか分からない。影が料理ごとに違う向き | 光源を 1 つだけ書く: 「窓からの午後の自然光、料理の斜め後ろから」「曇りの日のやわらかい光」「少し露出が暗め」。スタジオ照明・正面のフラッシュを避ける | 影の向きが全部そろっているか、ガラスや器の映り込みが周りと合うか | B〜C [18][19][24] |

## 色の決め方

**業種ごとの「定番色」は観察としてはあるが、色の心理学の根拠は弱い**(スキル表 #38)。
- 赤は食欲を上げる、とよく言われるが、研究はばらばら。店内の壁の赤は体に悪い料理を選ばせやすい(Szocs ら 2024、Journal of Consumer Psychology)一方、料理の皿や表示の赤は「止まれ」として量を減らす(2012、Appetite)。448 人の実験(2020、Frontiers in Psychology)では、赤で食欲が増す効果は出なかった [31]。**「飲食は赤」と決めつけず、店の物から拾う。**
- 観察(上の 41 件+319 件): 和食 = 黒・生成り・ベージュ+朱か金茶 / ラーメン = 黒白+赤・黄 / カフェ・洋菓子 = クリーム・茶+1 色 / 美容 = 白・ベージュ(美容 96 件中、白 40・ベージュ 30) / ジム = 白黒+鮮やかな 1 色 / 整体・ヘルスケア = 白+青・緑。

**店の実物から色を拾う手順**
1. **拾う物を 3 つ撮る**: のれん・看板・外壁 / 器・カウンター・床の木 / 制服・エプロン・ショップカード。昼の自然光で、正面から。
2. **写真から色を取り出す**: Adobe Color の「画像から抽出」に写真を入れると、自動で色の組み合わせが出る。点を動かして直し、雰囲気のプリセットで調整できる(無料。保存は Adobe のアカウントが要る)[32]。スマホの写真編集でスポイトを使ってもよい。
3. **役割を決めて 4〜6 色に**(#36): 背景(紙・壁の色)/ 文字(墨・焦げ茶。真っ黒にしない)/ アクセント 1 色(のれん・看板の色。予約ボタンだけに使う、#34)/ 区切り・薄い面 1〜2 色。
4. **実物の色をそのまま使えない時は明るさだけ変える**: のれんの紺が薄くてボタンの文字が 4.5:1 にならないなら、色味はそのままで暗くする(#35)。
5. **測る**: 文字 4.5:1・ボタンの枠 3:1(#31・#32)。
6. **背景は真っ白より、紙・生成りの白**。2026 年の Pantone も白だが(Cloud Dancer)[13]、店の実物の壁や紙の色の方が「この店らしさ」が出る。

## 未確認・意見が割れていること
- **ギャラリーの偏り**: MUUUUU・SANKOU! に載るのは制作会社の作品で、予算の大きいサイトが多い。今回の傾向は「よくできた店舗サイト」の傾向で、ふつうの個人店や、店主が「うちもこれくらいでいい」と思う水準を表してはいない。ノレンの見本に近いのは、ギャラリーの中でも 1 ページで写真が少ない店(NI to WA、Moch Pit、studio yoggy、BALANCE FITNESS GYM など)。
- **自分の集計の限界**: MUUUUU は各カテゴリの 1 ページ目だけ(新しい順)。タグは MUUUUU の運営者が付けたもの。書体と色は HTML と CSS から自動で抜き出したので、画像の中の文字や、JS で読む書体は拾えていない(7 サイトは読めず)。色の数え方は CSS に出てくる回数で、画面での面積ではない。
- **整体・接骨院の事例が少ない**: ギャラリーにほぼ載らない(MUUUUU に整体の分類がなく、SANKOU! も 1 件)。業種の型の整体の行は弱い。
- **「AI っぽさ」の特徴**: ほとんどがブログ・SNS・ツールの記事で、デザイナーへの体系的な調査は見つからなかった。Fountain Institute の 7 つ、utsubo の 12 個はどちらも筆者の見解。utsubo の「Figma 2026 年調査で 38%」は元の資料を確認していない。
- **AI っぽさを避ける訓練の副作用**: 「AI 感を見抜く」練習は、本物の写真を AI と間違える副作用があるという [18]。本物の写真でも「きれいすぎる」と AI に見られることがある。
- **トレンドの数字**: 「Awwwards の日替わり賞の 61% が 3D」は 1 社の記事だけで、Awwwards 自身の発表ではない [8]。Figma のトレンドのページも測定ではない。
- **「手触り・反 AI」のトレンド**: そう言っているのは手描き・印刷を売る会社やトレンド記事が多い。It's Nice That には、トレンド記事の「手作り」が本当に手作りか疑う記事もある [10]。
- **AI の料理写真と法律**: AI 画像そのものを禁じる国内の規定は見つからなかった。問題になるのは実物と違うとき(優良誤認)。消費者庁の資料で最新の扱いを確かめていない。「少し不完全な AI の料理画像が一番不気味に見える」という研究があるという記事もあったが、元の論文は確かめられなかった。
- **Google ビジネスプロフィールの写真の効果**: 「写真がある店は経路の検索 42%・サイトのクリック 35% 多い」は Google の説明として広く引用されるが、一次資料のページは確かめていない。営業資料では使わない。
- **「信頼できそう」の研究**: Fogg(Stanford、2002、2,684 人)の「信頼の判断に見た目が関わる 46.1%」は、人の割合ではなく**コメントの割合**とする出典もあり、どちらか決められなかった [33]。50ms の第一印象(Lindgaard)、見慣れた形と単純さ(Tuch)はスキル表 #8・#9 にある。店舗サイトに絞った「入りやすさ」の研究は見つからなかった。
- **Webflow の 2026 年トレンド記事**は読み込めず(ページの不具合)、中身を確認していない。
